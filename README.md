# 💰 AI Personal Finance Assistant

## 📌 Project Description
The AI Personal Finance Assistant is a Python-based web application designed to help users manage their personal finances. It allows users to track income and expenses, analyze spending patterns, manage budgets, set savings goals, detect unusual expenses, and predict future expenses using Machine Learning.
## 🚀 Features
- 💳 **Transaction Management** – Add and track income and expenses.
- 📊 **Financial Overview** – View total income, expenses, and savings.
- 📈 **Expense Analysis** – Analyze expenses using interactive charts.
- 💰 **Budget Management** – Set monthly budgets and monitor spending.
- 🎯 **Savings Goals** – Create and track personal savings goals.
- 🚨 **Anomaly Detection** – Identify unusual expenses using Machine Learning.
- 📉 **Expense Prediction** – Predict upcoming expenses using Linear Regression.
- 🏷️ **Expense Categorization** – Automatically categorize expenses based on descriptions.

## ⚙️ Installation and Setup
### Step 1: Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```
### Step 2: Navigate to the Project Folder
```bash
cd AI-Personal-Finance-Assistant
```
### Step 3: Install Required Libraries
```bash
pip install streamlit pandas plotly mysql-connector-python scikit-learn
```
### Step 4: Configure MySQL
- Install and open MySQL.
- Create the required database and tables.
- Configure your database username, password, and database name in `database.py`.
### Step 5: Run the Application
```bash
streamlit run app.py
```
The application will open in your web browser.
